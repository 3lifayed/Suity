# Library Database System

This is a C# Windows Forms Application built to demonstrate basic CRUD functionality using a local database. The system allows users to search for Books, Students, Publishers, and Libraries.

## Features

- Graphical User Interface using Windows Forms
- Organized selection of:
  - Suits (e.g., Giorgio Armani, Paul Smith)
  - Shirts (e.g., Gucci, Versace)
  - Shoes (e.g., Oxford, Monk)
- Color variants (Black, Blue, White) for each item
- Quantity selection using numeric input
- Total calculation button
- Reset and Exit functionality
- Structured codebase following software engineering and debugging principles

## Technologies Used

- C# (.NET Framework)
- Windows Forms (WinForms)
- SQL (for potential backend integration)
- Visual Studio 2022

## Getting Started

1. Clone the repository
2. Open the solution in **Visual Studio 2022**
3. Ensure that **.NET desktop development** workload is installed
4. Build the project (`Ctrl+Shift+B`)
5. Run the application (`F5`)
